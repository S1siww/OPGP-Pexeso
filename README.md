# 🧠 Pexeso v Pygame

Tento projekt je jednoduchá hra (hľadanie dvojíc) vytvorená v Pythone pomocou knižnice Pygame. Cieľom je nájsť všetky dvojice kariet na hernej ploche v čo najmenšom počte ťahov.

## 🎮 Funkcie

- Grafické rozhranie postavené na Pygame
- Jednoduché ovládanie pomocou myši
- Počítanie počtu ťahov
- Náhodné rozloženie kariet pri každom spustení
- Možnosť prispôsobenia veľkosti hracej plochy alebo obrázkov

## Spustenie

- hru spúšťame pomocou main.py
